WHAT MATCHES THE CURRENT WEBSITE
The site's footer presents the lowercase wordmark onesimplesite, with simple
highlighted in green. It uses Inter Variable at weight 700 and tracking -0.06em.
The vector wordmark is reconstructed from the actual font served by the live
site, with those settings; it is not an extracted pre-existing logo master.
Kerning is applied to the complete word before per-letter colour assignment;
browser rendering at inline colour boundaries can vary slightly.

FILES
01-SVG: outlined vector wordmarks.
02-PNG: transparent wordmarks (3000 px wide). PNG exports are RGBA, sRGB artwork.
03-PDF: vector versions for print and document workflows. White and reversed
PDFs include an ink-colour backdrop so the artwork can be seen.
SVG and PNG reversed/white versions have transparent backgrounds.
04-Reference: usage sheet and source record.

COLOURS (sRGB)
Ink: #0E1311
Light-surface wordmark accent / moss: #0C6A49
Dark-surface wordmark accent / spring: #4FD9A0
Reversed wordmark base / bone: #EFEBE3
Single-colour artwork: #000000 or #FFFFFF

USAGE
Keep the logo in its original proportions. Do not stretch or recolour it.
Leave at least one lowercase o's height clear around the wordmark.
For document headers, a wordmark width of 45-55 mm is a practical starting point.
Use black on white for small type, photocopying and formal documents.
Use reversed artwork on a dark, plain background.
The SVG files include a small export margin; add the clear space when placing.

FONT AND PROVENANCE
Inter, weight 700, is identified from the font served by the website. Logo text
is outlined, so installing the font is not required. Font licensing reference:
https://openfontlicense.org (licence URL embedded in the source font).
No font software is redistributed in this pack.
